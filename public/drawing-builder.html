SJ / DRAWING BUILDER

실제 롤 도안 생성

제작에 필요한 기본 형상, 축·베어링 시트, 표면 조건과 검사 기준을 입력하면 2D 제작 검토 도면을 바로 만들 수 있습니다.

기존 3D 도안 설계 ↗CAD 업로드 ↗
01

도안 기본 정보

견적과 제작 협의에 사용할 식별 정보를 먼저 입력합니다.

02

롤 외형과 축 치수

도안의 기준 형상을 결정하는 값입니다. 모든 길이는 선택한 단위로 입력합니다.

전체 길이1,400 mm= 좌측 축 + 몸통 면장 + 우측 축
03

저널·베어링 시트

베어링이 걸리는 위치와 길이를 별도로 표시합니다. 모르면 축 지름과 같은 값으로 시작한 뒤 상담 시 확정하세요.

도면은 시트 구간을 계단 형상으로 표시합니다. 베어링 번호, 끼워맞춤과 어깨 R은 설치 장치와 함께 최종 검토해야 합니다.
04

표면 패턴과 가공 형상

몸통 표면의 기본 패턴을 정하면 도면의 외형과 홈 정보를 함께 표시합니다.

05

공차·검사·제작 조건

값을 비워 두지 않고 “협의”라고 적어 두면 제작 검토 목록에 남습니다.

    사용 순서

    1. 몸통 면장·외경과 좌우 축 길이를 입력합니다.
    2. 베어링 시트 길이·지름과 표면 패턴을 정합니다.
    3. 공차·런아웃·표면·밸런스 조건을 채웁니다.
    4. 실제 도안 생성 후 SVG·DXF 또는 JSON으로 저장합니다.
    5. 3D 설계로 보내거나 CAD를 업로드해 입체 형상을 확인합니다.
