# SJ-I160 중공형 웹 가이드 롤

홈페이지 기존 롤과 다른 **고정축·회전 몸통 방식**의 업로드 시험용 예제입니다. 필름·부직포 등의 원단 이송용 비구동 가이드 롤 구조를 가정했습니다. 실제 납품품이나 제작 승인 도면이 아닙니다.

## 파일과 사용법

1. 도안 설계 페이지에서 **도면 업로드 · 3D 적용**을 누릅니다.
2. `sj-i160-idler-assembly.step`을 선택하면 44개 부품 조립체가 표시됩니다.
3. 단면 보기, 윤곽선, 부품 선택으로 몸통·축·엔드캡·베어링·커버·볼트를 확인합니다.
4. `sj-i160-shell-profile.dxf`를 선택하면 몸통의 닫힌 반단면을 X축 기준 360° 회전한 중공 몸통이 생성됩니다. DXF에는 베어링·축·볼트가 포함되지 않습니다.
5. 치수를 읽으려면 `sj-i160-drawing.pdf`를 봅니다. PDF는 변환 입력이 아니라 열람용입니다.

## 주요 치수 (mm)

| 항목 | 값 |
|---|---:|
| 축 포함 전체 길이 | 830 |
| 몸통 길이 | 700 |
| 몸통 외경 / 내경 | 160 / 144 |
| 중앙 축 / 베어링 축 / 설치 축단 지름 | 40 / 35 / 30 |
| 베어링 외형 (내경 × 외경 × 폭) | 35 × 72 × 17 |

몸통은 AL6061, 축은 S45C를 예시로 지정했습니다. STEP은 부품별 색상·이름을 보존하는 솔리드 CAD이며, 삼각망을 CAD처럼 이름만 바꾼 파일이 아닙니다. 베어링 레이스·실·볼·클램프와 나사산은 설명용으로 단순화했습니다.

## 제작 전 검토

하중, 회전수, 웹 장력, 축 처짐, 임계속도, 베어링 수명, 고정측/자유측 축방향 구속, 온도 변화, 끼워맞춤, 표면 조도, 런아웃, 밸런싱, 클램프 고정 및 볼트 체결을 실제 설치 조건에 맞게 설계해야 합니다. 이 예제는 해당 계산이나 제작 공차를 보증하지 않습니다.

## 설계 참고

알루미늄 튜브·베어링을 이용하는 웹 이송 롤의 적용 분야는 제조사 [Montalvo Load Cell Roll Assembly](https://montalvo.com/products/load-cell-roll-assembly-lcr/) 설명을 참고했습니다. 본 예제에는 로드셀이 없으며, 제조사 설계나 성능 수치를 복제하지 않았습니다. 치수와 형상은 이 예제를 위해 새로 정했습니다.

## 재생성
